This file documents the wiki page template — duplicated into each page since we
serve static HTML with no build step. Update by hand if shared structure changes.

The structure of every wiki page is:

  <head>     — meta + canonical + stylesheet
  header.nav — top nav (matches index.html's nav)
  main.wrap > .wiki-shell
    aside.wiki-side  — navigation tree (matches /wiki/index.html)
                       mark current page with class="current"
    section.wiki-content > article.prose
      header.page-head — crumb, h1, lede
      … content …
      .next-prev — prev/next page links
  footer  — same as index.html (compact version)
