What changed (and why)

  • moved Toolbar to the top. macOS apps put primary actions in NSToolbar; bottom button-strips read as "modal dialog," not "library window."
  • moved Buttons grouped logically. Primary (Start) on the left, creation cluster, modification cluster, destructive (Delete) on the right with a red tint and a clear visual gap.
  • new Sidebar = navigation, not status. Filters (state, OS, network) replace the "Active VMs" status panel — selection lives in the table instead of being duplicated in the sidebar.
  • new Selected VM detail card. Below the table, shows uptime / CPU / memory / network / mode for the highlighted row. Currently the only feedback for selection is button enablement.
  • new Traffic sparkline column. Per-row glimpse of network activity without opening Packet Analysis.
  • gone Bottom packet log strip. Demoted — Packet Analysis already has a dedicated window, and the strip was a cramped duplicate. The protocol legend lives there instead.
  • gone Right-side VMs/Tasks tab panel. The VMs tab duplicated the main table; Tasks moves to a slide-out drawer triggered from the status bar.

Color & typography

  • moved Cyan warmed ~10° toward azure (#00b6e6 vs current #00b3e6). Reads less arcade-neon, more instrumentation-cluster.
  • gone Chartreuse "VF" green dropped. It clashed with the cyan and looked unintentional. Branding stays single-tone with subtle weight contrast.
  • new SF Mono for VM names + numerics. Tactical aesthetic, easier to scan IPs/MACs/byte counts, matches what a malware analyst expects.
  • new Status pills replace inline text. Compact, color-coded, easier to spot at a glance than "● Running" mixed into a sentence.
  • tighter Single source for status colors. Running = green, paused = yellow, stopped = grey, danger = red. Same hue in pills, dots, sparklines, status bar.
  • new One spacing scale (4-pt grid). Token names already landed in LayoutConstants.swift — spacingXS/SM/MD/LG/XL/XXL. Mockup uses them throughout.

Information density wins

  • Table grew 2 columns (CPU·RAM, Disk, Traffic) without scrolling, because the sidebar shrunk from a "status panel" to filters.
  • Disk usage in-line. "12 / 32 GB" tells the story; no need to open Configure to check.
  • Live status pulse in the status bar reflects whether the virtual switch + capture pipeline are healthy. Currently spread across three places.
  • No more "right-panel Tasks tab" for long-running operations — moved to a status-bar-triggered drawer, freeing horizontal space.

Migration cost (rough)

  • Top toolbar: swap XIB layout, wire NSToolbar. ~half a day.
  • Sidebar filter list: new NSOutlineView data source. ~1 day; mostly state plumbing.
  • Detail card: new view, bind to tableViewSelectionDidChange. ~half a day.
  • Sparklines: a custom NSView subclass, ~2 hrs (data already flows through PacketCaptureManager).
  • Color migration: already half-done — tokens exist in AppColors; remaining literals can be mopped up incrementally.
  • Status bar: small reorg of VMLibraryWindowController.statusBar; mostly wiring existing publishers.
